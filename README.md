# 愛東農園 ホームページ

マスカット・ベーリーA を栽培するぶどう園の、シンプルな1ページ構成のホームページです。
`index.html` だけで完結しているので、ブラウザで開くだけで表示できます。

## 構成

| セクション | 内容 |
| --- | --- |
| メインビジュアル | ぶどうのイラストとキャッチコピー |
| ぶどう園について | 園の紹介 |
| マスカット・ベーリーAとは | 品種の特長を3つ紹介 |
| 商品紹介 | ぶどうジュース（720ml）と赤ワイン（750ml） |
| ぶどう園の1年 | 1月〜3月／4月〜6月／7月〜8月／9月〜10月の作業 |
| ご購入・お問い合わせ | 所在地・営業時間・電話番号 |

## 書き換えてほしいところ

`index.html` の中の次の部分を、実際の情報に差し替えてください。

1. `滋賀県東近江市愛東町` … 郵便番号と番地を足してください（お問い合わせ欄とフッターの2か所）
2. `000-000-0000` … 電話番号（`<a href="tel:000-000-0000">` の中にもあるので2か所）
3. `○,○○○円` … ジュースとワインの価格（2か所）
4. `毎週○曜日` … 定休日
5. `9:00〜17:00` … 営業時間（今は仮の時間です）

園名（愛東農園）と所在地（滋賀県東近江市愛東町）はすでに入れてあります。

## 写真を入れる場合

商品画像は今はイラスト（SVG）です。実際の写真に差し替えるときは、
`<div class="product-image juice">` の中身を次のように置き換えてください。

```html
<div class="product-image juice">
  <img src="images/juice.jpg" alt="ベーリーA ぶどうジュース">
</div>
```

あわせて CSS の `.product-image` に `overflow: hidden;` を、
`.product-image img` に `width: 100%; height: 100%; object-fit: cover;` を足すときれいに収まります。

## 公開方法

サーバーに `index.html` をアップロードするだけで公開できます。
GitHub Pages を使う場合は、リポジトリの Settings → Pages でブランチを指定してください。
