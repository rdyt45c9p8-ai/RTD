# 検索ポイント ヘルパー（非公式）

Microsoft Rewards の検索枠を、**検索ワードを考える手間なし**でこなすための補助アプリです。
`index.html` ひとつだけなので、ダウンロードしてブラウザ（Edge）で開くだけで使えます。

## このアプリがやること／やらないこと

| | |
| --- | --- |
| やる | 検索ワードを毎日自動で42個用意する・進捗と見込みポイントの集計・デイリーセットのチェック・獲得ポイントの記録とグラフ |
| やらない | **検索の自動実行**（ボットによる自動検索は Rewards の規約違反で、ポイント没収やアカウント停止の対象です） |

検索はボタンを押した分だけ、あなたの操作として実行されます。

## 使い方

1. Edge で Microsoft アカウントにサインインしておく
2. `index.html` をブラウザで開く
3. 「パソコン検索」タブで大きいボタンを押す → 新しいタブで検索され、次のワードに自動で進む
4. キーボードの **Space（またはEnter）** でも同じ。目標回数まで押し続けるだけ
5. スマホで同じファイルを開き、「モバイル検索」タブで同様に（モバイル枠はスマホでの検索が対象）
6. Rewards の画面で見た今日の合計ポイントを「獲得ポイントの記録」に入れると、14日分のグラフと目標までの日数が出ます

### 画面の見かた

- **残り検索回数** … 今選んでいるタブ（PC／モバイル）の残り
- **今日の見込みポイント** … PC＋モバイルの合計（1日の上限で頭打ちになります）
- **リセットまで** … 設定した日次リセット時刻までの残り時間
- **このワードを飛ばす** … 検索せずに次へ。回数にもポイントにも数えません
- **1つ戻す** … 直前の1件を取り消し

## 設定（自分の条件に合わせてください）

| 項目 | 初期値 | 補足 |
| --- | --- | --- |
| パソコン検索の目標回数 | 30 | レベルや地域で変わります |
| モバイル検索の目標回数 | 20 | 同上 |
| 1検索あたりのポイント | 3 | |
| 1日の上限ポイント（PC／モバイル） | 90 ／ 60 | 0 にすると上限なしで計算 |
| リセット時刻 | 16時 | この時刻で「翌日分」に切り替わります |
| 交換したい目標ポイント | 5000 | 達成までの日数の目安が出ます |
| 検索エンジンのURL | `https://www.bing.com/search?q=` | 末尾にワードが付きます |

## データについて

- 記録はすべて**使っているブラウザの中（localStorage）だけ**に保存され、外部には一切送信しません
- 「データを書き出す」で JSON に保存、「データを読み込む」で別の端末に引き継げます
- ブラウザの履歴・サイトデータを消すと記録も消えます。大事な記録は書き出しておいてください
