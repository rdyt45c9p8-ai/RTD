はじめに読んでください（自動検索はしません）
このアプリがやるのは「検索ワードを自動で大量に用意する」ところまでです。検索そのものはボタンを押したあなたの操作で行われます。
  • ボットやマクロで検索を自動実行すると Microsoft Rewards の規約違反になり、ポイント没収やアカウント停止の対象になります。このアプリにその機能は入れていません。
  • ポイントが入るのは Microsoft アカウントでサインインした状態の検索だけです。先に Edge でサインインしておいてください。
  • モバイル検索枠は、スマホの Edge か Bing アプリでの検索が対象です。このページをスマホで開いて使ってください。
  • 目標回数・1検索あたりのポイント・リセット時刻は地域やレベルで変わります。設定で自分の条件に合わせてください。
