# ミニゲーム50

落ちものブロック・スネーク・ブロック崩しのような、シンプルなミニゲームを **50本** 入れたゲーム集です。
各ゲームのハイスコアをオンラインのランキングで競えます。

## 遊び方

| 遊び方 | ランキング |
| --- | --- |
| `index.html` をブラウザで直接ひらく | このブラウザの中だけに記録（オフライン） |
| `node server.js` で起動して `http://localhost:8080` をひらく | 同じサーバーにつないだ全員で競える |
| claude.ai の Artifact として公開したページ | リンクをひらいた全員で競える（共有データベース） |

操作はキーボード（矢印キー / WASD、スペース・Enter・Z が A ボタン、Esc で一覧へ）、
マウス、スマホのタッチ（画面ボタンつき）に対応しています。

## ランキングのしくみ

- ゲームごとに、各プレイヤーの自己ベストだけを記録します。
- 総合ランキングは、各ゲームの 1位に10点、2位に9点 … 10位に1点を足した合計です。
- ニックネームは画面右上で変えられます（12文字まで）。

## ファイル構成

```
mini-games-50/
├── index.html      … 遊ぶファイル（src から自動で作る）
├── server.js       … ランキングサーバー（Node.js だけで動く）
├── build.js        … src をまとめて index.html を作る
└── src/
    ├── shell.html  … 画面のレイアウトとデザイン
    ├── engine.js   … ゲームの共通しくみ（描画・入力・効果音）
    ├── games-01.js … ゲーム 1〜10
    ├── games-02.js … ゲーム 11〜20
    ├── games-03.js … ゲーム 21〜30
    ├── games-04.js … ゲーム 31〜40
    ├── games-05.js … ゲーム 41〜50
    ├── net.js      … ランキング（オンライン / サーバー / このブラウザだけ）
    └── ui.js       … 一覧・プレイ画面・ランキング表示
```

`src` を書きかえたら `node build.js` で `index.html` を作りなおしてください。
